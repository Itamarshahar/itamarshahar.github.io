# itamarshahar.github.io

Personal landing page. Static site built on the HTML5 UP "Aerial" template —
one `index.html`, hand-edited CSS in `assets/css/main.css` (compiled from
`assets/sass/`). No build step, no package manager. Deployed by GitHub Pages
from `main`.

## Agent skills

### Issue tracker

Issues live as GitHub issues on `Itamarshahar/itamarshahar.github.io`, managed
with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, label string equal to role name. See
`docs/agents/triage-labels.md`.

### Domain docs

Single-context — `CONTEXT.md` and `docs/adr/` at the repo root. See
`docs/agents/domain.md`.
